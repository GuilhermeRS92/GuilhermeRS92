# Olá! 👋 Sou o Guilherme Ribeiro

**Software Engineer | Front-End Angular | TypeScript | Node.js & NestJS | BFF | AI-Assisted Development**

Sou um Engenheiro de Software com cerca de 4 anos de experiência no desenvolvimento de aplicações web robustas e escaláveis. Atualmente, contribuo para a evolução de plataformas financeiras e arquiteturas multi-tenant (Open Finance e White Label), com impacto direto na otimização de jornadas complexas e redução de custos operacionais.

🚀 **O que eu faço:**
* **Front-End Avançado:** Especialista em **Angular** e **TypeScript**, aplicando práticas modernas como **RxJS**, **Signals** e **Reactive Forms**.
* **BFF e Arquitetura:** Desenvolvimento de Backend-for-Frontend (BFF) utilizando **Node.js**, **Express** e **NestJS** para integrar microsserviços e sistemas legados.
* **AI-Assisted Development:** Forte exploração de engenharia de software assistida por IA (Context Engineering, Vibe Coding), integrando ferramentas de inteligência para refinar arquiteturas e acelerar entregas de valor.
* **Qualidade e CI/CD:** Cultura de testes automatizados (Jest), code reviews, documentação técnica e observabilidade.
